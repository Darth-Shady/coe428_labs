# COE428 — Algorithms and Data Structures

This repository contains the **laboratory coursework and corresponding documentation** completed throughout COE428, focusing on the design, implementation, and analysis of algorithms and data structures using the C programming language.

## Learning Outcomes

By the end of the course, the coursework demonstrates the ability to:

* **Design and analyze algorithms** for solving computational problems in engineering. **(1a)**
* **Analyze algorithmic complexity**, including best-, worst-, and average-case running times, using asymptotic notation and recurrence equations. **(1b)**
* **Apply appropriate data structures** to construct efficient solutions to engineering and computational problems. **(1c)**
* **Analyze and compare graph algorithms** for solving network and other graph-based problems. **(4b)**
* **Compare algorithm design approaches**, including incremental and divide-and-conquer methods, and select appropriate approaches based on problem characteristics and input size. **(4c)**
* **Implement required algorithms while following laboratory and assessment specifications.** **(7a)**

## Topics Covered

The labs cover fundamental concepts in algorithms and data structures, including:

* Algorithm analysis and **time/space complexity**
* Best-, worst-, and average-case analysis
* **Big-O and asymptotic notation**
* Recurrence equations and their analysis
* Divide-and-conquer algorithms
* Searching and sorting algorithms
* Arrays and pointers
* Stacks and queues
* Linked and doubly linked lists
* Binary trees and binary search trees
* Red-black trees
* Heaps and priority queues
* Hash tables
* Recursive algorithms
* Graph representations and algorithms
* Breadth-first search (BFS)
* Depth-first search (DFS)
* Dijkstra's shortest-path algorithm
* Parsing and related computational techniques
* NP-complete problems
* Object-oriented data structures
* Software engineering and project management concepts
